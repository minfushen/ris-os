# 企业风险评估 Agent 用户手册

## 1. 功能介绍

### 1.1 什么是企业风险评估 Agent？

企业风险评估 Agent 是一个智能化的企业风险评估工具，基于企查查 MCP 实时数据，提供：

- **9 维度风险评估**：全面评估企业商业、运营、财务、合规等风险
- **18 类风险排查**：排查失信、被执行人、经营异常等 18 类风险
- **风险分级**：自动将风险分为 CRITICAL/HIGH/MEDIUM/LOW 四个等级
- **证据链生成**：提供完整的风险证据链，支持决策
- **处置建议**：根据风险等级提供处置建议和响应时间

### 1.2 适用场景

- **贷后风控**：评估借款企业风险，制定风控策略
- **供应商管理**：评估供应商风险，保障供应链稳定
- **客户准入**：评估新客户风险，制定合作策略
- **预警核查**：深入了解预警原因，制定核查方案

## 2. 快速开始

### 2.1 访问入口

**路径**：智能体协同 → 企业风险评估 Agent

**URL**：`/agents/vendor-risk-assessment`

### 2.2 基本操作流程

1. **输入企业名称**
   - 在输入框中输入企业名称或统一社会信用代码
   - 例如：`华为技术有限公司` 或 `91440300123456789X`

2. **开始评估**
   - 点击"开始评估"按钮
   - 系统将调用企查查 MCP 进行评估
   - 评估时间约 1-3 秒

3. **查看结果**
   - 整体风险等级
   - 9 维度评估详情
   - 18 类风险清单
   - 证据链
   - 处置建议

## 3. 功能详解

### 3.1 整体风险评估

**风险等级**：

| 等级 | 颜色 | 含义 | 响应时间 |
|------|------|------|---------|
| 🔴 CRITICAL | 红色 | 立即供应中断 | < 4 小时 |
| 🟠 HIGH | 橙色 | 供应不稳定 | < 24 小时 |
| 🟡 MEDIUM | 黄色 | 财务/合规风险 | < 72 小时 |
| 🟢 LOW | 绿色 | 一般合规风险 | < 1 周 |

**示例**：
```
整体风险等级：🟢 LOW
企业名称：华为技术有限公司
评估时间：2026-04-27T10:30:00
```

### 3.2 9 维度评估详情

**基础 6 维度**：

1. **商业风险**（合同与交易）
   - 合同纠纷
   - 交易异常
   - 商业信誉

2. **运营风险**（交付能力）
   - 经营异常
   - 停产停业
   - 产能不足

3. **财务风险**（资金健康）
   - 财务数据异常
   - 资金链断裂
   - 债务风险

4. **合规风险**（认证与处罚）
   - 行政处罚
   - 环保处罚
   - 税务异常

5. **战略风险**（依赖程度）
   - 客户集中度过高
   - 供应商依赖

6. **地缘政治风险**（宏观环境）
   - 区域风险
   - 政策风险

**供应链特有 3 维度**：

7. **产能资质风险**
   - 生产许可
   - 质量认证
   - 行业资质

8. **组织稳定性风险**
   - 股权变更
   - 核心人员变动
   - 单点风险

9. **业务健康度风险**
   - 信用评级
   - 招投标活跃度
   - 融资情况

**示例**：
```
财务风险：🟢 LOW
风险分数：18.3
关键发现：
  - 财务状况良好
证据：
  - 2024年财报显示营收增长20%
```

### 3.3 18 类风险清单

**CRITICAL（立即供应中断）**：

| 风险类型 | 说明 | 影响 |
|---------|------|------|
| 破产重整 | 企业进入破产重整程序 | 可能无法继续交付 |
| 失信信息 | 被列为失信被执行人 | 信用严重受损 |
| 被执行人 | 有执行案件未履行 | 资金链可能断裂 |
| 环保处罚（停产） | 环保问题导致停产 | 无法正常生产 |
| 经营异常 | 通过登记的住所无法联系 | 经营状况不明 |

**HIGH（供应不稳定）**：

| 风险类型 | 说明 | 影响 |
|---------|------|------|
| 严重违法 | 严重违法行为 | 可能被吊销执照 |
| 注销备案 | 正在办理注销 | 即将停止经营 |
| 股权冻结 | 股权被司法冻结 | 股权转让受限 |
| 限制高消费 | 被限制高消费 | 资金周转困难 |

**MEDIUM（财务/合规风险）**：

| 风险类型 | 说明 | 影响 |
|---------|------|------|
| 股权出质 | 股权已出质 | 融资压力大 |
| 欠税公告 | 欠税金额较大 | 税务风险 |
| 税务异常 | 税务状态异常 | 合规风险 |
| 终本案件 | 执行案件已终本 | 债务未清偿 |
| 动产抵押 | 动产已抵押 | 资产受限 |

**LOW（一般合规风险）**：

| 风险类型 | 说明 | 影响 |
|---------|------|------|
| 一般行政处罚 | 一般性违法 | 轻微合规问题 |

**示例**：
```
风险类型：财务风险
风险等级：🟡 MEDIUM
风险描述：存在欠税记录
证据内容：欠税金额 50 万元
供应链影响：可能影响资金周转
处置建议：核实欠税原因和补缴计划
响应时间：< 72 小时
```

### 3.4 证据链

**证据项**：
- **数据来源**：企查查-财务数据
- **更新时间**：2024-12-31
- **可信度**：高
- **内容**：2024年财报显示营收增长20%

**用途**：
- 支持风险评估结论
- 提供决策依据
- 可追溯数据来源

### 3.5 处置建议

**建议内容**：
- **处置动作**：定期跟踪财务状况
- **SLA**：< 1 周
- **责任人**：风控经理
- **补充材料**：最新财报、银行流水

**示例**：
```
处置动作：核实欠税原因和补缴计划
SLA：< 72 小时
责任人：风控经理
补充材料：
  - 欠税公告详情
  - 企业财务报表
  - 补缴计划书
```

## 5. 常见问题

### 5.1 评估失败怎么办？

**可能原因**：
- 企业名称输入错误
- 企业不存在
- 网络连接问题
- MCP 服务不可用

**解决方法**：
1. 检查企业名称是否正确
2. 尝试使用统一社会信用代码
3. 稍后重试
4. 联系技术支持

### 5.2 评估结果不准确怎么办？

**可能原因**：
- 企查查数据更新延迟
- 企业信息不完整
- 评估模型局限性

**解决方法**：
1. 查看数据更新时间
2. 结合其他信息源验证
3. 咨询风控专家

### 5.3 如何理解风险等级？

**CRITICAL（关键风险）**：
- 含义：立即供应中断
- 响应：< 4 小时
- 行动：立即启动应急预案

**HIGH（高风险）**：
- 含义：供应不稳定
- 响应：< 24 小时
- 行动：密切监控，准备备选方案

**MEDIUM（中等风险）**：
- 含义：财务/合规风险
- 响应：< 72 小时
- 行动：评估长期影响，制定应对策略

**LOW（低风险）**：
- 含义：一般合规风险
- 响应：< 1 周
- 行动：跟踪整改情况

### 5.4 如何使用处置建议？

**步骤**：
1. 查看处置建议
2. 确认责任人
3. 准备补充材料
4. 在 SLA 时间内完成处置
5. 记录处置结果

## 6. 最佳实践

### 6.1 定期评估

- **频率**：建议每季度评估一次重要客户/供应商
- **触发条件**：重大预警、合作前、定期审查

### 6.2 多维度分析

- 不要仅看整体风险等级
- 关注 9 维度评估详情
- 结合 18 类风险清单
- 查看证据链支持决策

### 6.3 协同使用

- 与预警归因 Agent 配合使用
- 与处置建议 Agent 配合使用
- 在预警核查工作台查看风险评估结果

### 6.4 数据验证

- 查看数据更新时间
- 结合其他信息源验证
- 必要时进行实地核查
