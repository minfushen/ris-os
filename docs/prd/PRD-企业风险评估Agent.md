# 企业风险评估 Agent 产品需求文档

## 1. 产品概述

### 1.1 产品背景

贷后风控管理平台（风控侠 v2）当前所有 Agent 都使用静态演示数据，缺乏真实 API 调用。为提升平台实用性和演示效果，需要集成企查查 MCP 服务，新增"企业风险评估 Agent"，提供真实的企业风险评估能力。

### 1.2 产品定位

企业风险评估 Agent 是一个底层能力 Agent，提供：
- **核心能力**：企业风险的自动化评估、分级和证据链生成
- **数据来源**：企查查 MCP 实时数据（65 个工具，4 个服务）
- **评估维度**：9 维度风险评估（基础 6 维 + 供应链特有 3 维）
- **风险分级**：18 类风险，4 级分类（CRITICAL/HIGH/MEDIUM/LOW）

### 1.3 目标用户

- **风控经理**：评估企业风险，制定风控策略
- **RM（客户经理）**：查看预警详情，了解客户风险状况
- **系统**：作为底层能力，被其他 Agent 调用（预警归因、处置建议）

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 企业风险评估

**输入**：
- 企业名称或统一社会信用代码
- 评估维度配置（可选：9 维度全量或自定义）
- 风险等级阈值配置（可选）

**处理流程**：
1. 调用企查查 MCP 获取企业数据（工商、司法、经营、知识产权）
2. 执行 9 维度风险评估
3. 排查 18 类风险并分级
4. 生成结构化证据链
5. 生成处置建议

**输出**：
- 整体风险等级（CRITICAL/HIGH/MEDIUM/LOW）
- 9 维度评估详情
- 18 类风险清单
- 证据链
- 处置建议

#### 2.1.2 9 维度评估

**基础 6 维度**：
1. **商业风险**（合同与交易）：合同纠纷、交易异常、商业信誉
2. **运营风险**（交付能力）：经营异常、停产停业、产能不足
3. **财务风险**（资金健康）：财务数据异常、资金链断裂、债务风险
4. **合规风险**（认证与处罚）：行政处罚、环保处罚、税务异常
5. **战略风险**（依赖程度）：客户集中度过高、供应商依赖
6. **地缘政治风险**（宏观环境）：区域风险、政策风险

**供应链特有 3 维度**：
7. **产能资质风险**：生产许可、质量认证、行业资质
8. **组织稳定性风险**：股权变更、核心人员变动、单点风险
9. **业务健康度风险**：信用评级、招投标活跃度、融资情况

#### 2.1.3 18 类风险排查

**CRITICAL（立即供应中断）**：
- 破产重整
- 失信信息（失信被执行人）
- 被执行人
- 环保处罚（停产）
- 经营异常（通过登记的住所无法联系）

**HIGH（供应不稳定）**：
- 严重违法
- 注销备案
- 股权冻结
- 限制高消费

**MEDIUM（财务/合规风险）**：
- 股权出质
- 欠税公告
- 税务异常
- 终本案件
- 动产抵押

**LOW（一般合规风险）**：
- 一般行政处罚

### 2.2 辅助功能

#### 2.2.1 历史评估记录

- 查看企业的历史评估记录
- 风险趋势分析
- 评估结果对比

#### 2.2.2 风险趋势分析

- 风险等级变化趋势
- 关键风险指标变化
- 预警信号演化

### 2.3 Agent 协同

#### 2.3.1 与预警归因 Agent 协同

**调用场景**：预警归因 Agent 需要外部风险数据时

**调用方式**：
```typescript
const riskAssessment = await api.assessVendorRisk(companyName);
```

**数据流**：
- 输入：企业名称
- 输出：风险评估结果（风险等级、证据链、处置建议）
- 归因 Agent 聚合外部风险和内部信号，生成归因摘要

#### 2.3.2 与处置建议 Agent 协同

**调用场景**：处置建议 Agent 需要企业风险详情时

**调用方式**：
```typescript
const riskAssessment = await api.assessVendorRisk(companyName);
```

**数据流**：
- 输入：企业名称
- 输出：风险评估结果
- 处置建议 Agent 匹配处置 SOP，生成处置建议

## 3. 非功能需求

### 3.1 性能要求

- API 响应时间 < 3 秒（P95）
- 并发支持 10 QPS
- 错误率 < 1%

### 3.2 安全要求

- API Key 通过环境变量管理，不硬编码
- 企业敏感数据不记录日志
- 访问控制：仅授权用户可访问

### 3.3 可用性要求

- 企查查 MCP 服务不可用时，提供降级方案
- 数据更新时间明确标注
- 错误信息用户友好

## 4. 用户故事

### 4.1 风控经理评估企业风险

**作为** 风控经理
**我想要** 输入企业名称，获取风险评估报告
**以便于** 了解企业风险状况，制定风控策略

**验收标准**：
- 输入企业名称后，3 秒内返回评估结果
- 评估结果包含 9 维度详情、18 类风险清单、证据链、处置建议
- 风险等级清晰明确（CRITICAL/HIGH/MEDIUM/LOW）

### 4.2 RM 查看预警详情

**作为** RM
**我想要** 在预警核查工作台查看企业的风险评估结果
**以便于** 了解预警原因和核查重点

**验收标准**：
- 工作台展示企业的风险评估结果
- 风险画像包含整体风险等级和关键风险
- 触发信号包含企查查数据

### 4.3 系统自动生成处置建议

**作为** 系统
**我想要** 调用企业风险评估 Agent，获取风险详情
**以便于** 生成处置建议

**验收标准**：
- 处置建议 Agent 可调用企业风险评估 Agent
- 调用返回结构化的风险评估结果
- 处置建议基于风险评估结果生成

## 6. 附录

### 6.1 企查查 MCP 服务

**4 个服务，65 个工具**：

- **qcc-company**（12 tools）：企业工商信息
  - get_company_registration_info
  - get_shareholder_info
  - get_key_personnel
  - get_branches
  - get_change_records
  - ...

- **qcc-risk**（34 tools）：企业风险信息
  - get_dishonest_info
  - get_judgment_debtor_info
  - get_high_consumption_restriction
  - get_abnormal_operation
  - ...（其他 14 类风险）

- **qcc-operation**（13 tools）：企业经营信息
  - get_qualifications
  - get_administrative_licenses
  - get_bidding_info
  - get_credit_rating
  - ...

- **qcc-ipr**（6 tools）：知识产权信息
  - get_patent_info
  - get_trademark_info
  - ...

### 6.2 风险等级定义

| 等级 | 含义 | 响应时间 | 供应链影响 |
|------|------|---------|-----------|
| CRITICAL | 立即供应中断 | < 4 小时 | 供应商可能已无法交付，需立即启动备选方案 |
| HIGH | 供应不稳定 | < 24 小时 | 供应商交付能力严重受损，需密切监控 |
| MEDIUM | 财务/合规风险 | < 72 小时 | 存在财务或合规问题，需评估对长期合作的影响 |
| LOW | 一般合规风险 | < 1 周 | 轻量合规问题，需跟踪整改情况 |
